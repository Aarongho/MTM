Remarks Classifier

Klasifikasi waterfall otomatis untuk kolom Remarks pada data validasi klaim (Aman / Validasi Doc Utama / Others Validation / Doc Non GL / Only Doc GL). Upload file Excel atau ZIP berisi banyak file — semua diproses langsung di browser kamu.

Pengaturan lanjutan
Tarik & lepas file .xlsx atau .zip di sini
atau klik untuk memilih file — bisa banyak file .xlsx sekaligus, atau satu/lebih file .zip berisi banyak .xlsx

    Contoh output (angka contoh, bukan hasil upload)

    KategoriJumlahSisa
    All data120
    Aman (tidak match Filter 1)20
    Validasi Doc Utama (match Filter 1)100
    Others Validation (match Filter 2)1090
    Doc Non GL (match Filter 3)1575
    Only Doc GL (sisa akhir)75
    🔒 Semua proses terjadi di browser kamu. File yang di-upload gak pernah dikirim ke server manapun — parsing, klasifikasi, sampai penulisan file hasil semuanya jalan lokal.
    Cara kerja: tiap baris dicek berurutan — dulu Filter 1 (5 frasa "Document belum diupload : ...") menentukan Aman vs Validasi Doc Utama, lalu Filter 2 (6 frasa "Result : ...") memisahkan Others Validation, sisanya dicek Filter 3 (4 frasa dokumen non-GL) untuk Doc Non GL vs Only Doc GL. Pencocokan pakai regex yang tahan spasi ganda/tab/newline dan tanda kutip/titik koma di sekitar frasa.
